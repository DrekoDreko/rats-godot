# Project Instructions

- Keep all generated code in English.
- Follow GDScript best practices.
- Every UI text element must use `scenes/big_font_outlined_label.tscn`; never use a standalone `Label` for interface text. This centralizes the project's font, outline, spacing, margins, and alignment so every interface keeps the same visual identity and remains consistent across screens and resolutions. Configure the reusable scene's exported properties instead of styling a raw `Label` directly.
